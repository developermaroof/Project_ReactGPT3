# Screenshots Directory

This folder contains screenshots of the GPT-3 OpenAI website.

## How to Add Screenshots

### Method 1: Using Browser DevTools (Recommended)

1. **Open your website** in Chrome/Firefox
2. **Open DevTools** (F12 or Right-click → Inspect)
3. **Toggle Device Toolbar** (Ctrl+Shift+M or Cmd+Shift+M)
4. **Select device** (iPhone, iPad, Desktop)
5. **Take screenshot:**
   - Chrome: Click the three dots → Capture screenshot
   - Or use browser extensions like "Full Page Screen Capture"

### Method 2: Using Online Tools

1. **Screely** - https://screely.com/
   - Upload screenshot
   - Get professional browser mockup

2. **Mockuuups Studio** - https://mockuuups.studio/
   - Create device mockups
   - Professional presentation

3. **Responsively App** - https://responsively.app/
   - Test multiple devices at once
   - Capture all views simultaneously

4. **mobile-home.png** - Mobile homepage
5. **mobile-menu.png** - Mobile navigation menu

### Screenshot Tips

- **Resolution**: Use at least 1920x1080 for desktop
- **Format**: PNG for best quality
- **File Size**: Optimize images (use TinyPNG.com)
- **Naming**: Use descriptive names (desktop-home.png)
- **Showcase**: Highlight key features and sections
